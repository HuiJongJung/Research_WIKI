## 1. 한 줄과 표적

**hole(개구부가 좁아 관측 다양성이 구조적으로 낮은 깊은 내부)이 있는 단일 오브젝트에서 GS 기반 mesh 재구성 품질을 개선한다.**

- 표적은 **hole의 유무(이분법)가 아니라 깊이 대비 개구부의 좁음(연속량)**이다. 그림도 성공/실패 두 장이 아니라 **연속으로 무너지는 곡선**을 지향한다
- 관통 구멍(가위 손잡이)은 표적이 아니다 — 양쪽에서 보인다. 단 이 가정은 **검증 중**이며 scan69 실측으로 확인한다
- 질감 있는 오목은 photo-consistency가 깎으므로(Kutulakos & Seitz §2.2), 남는 표적은 **어둡거나 무질감인 깊은 내부**다

## 2. 문제 제기의 뼈대 (근거 완비 — 이대로 슬라이드가 된다)

네 층이 서로 독립 경로로 같은 결론에 도달한다. **이것이 현재 가장 강한 재료다.**

1. **원리적으로 결정 불가한 영역이 존재한다** — Kutulakos & Seitz (IJCV 2000) §1.1 `[원문 확인]`: "no finite set of input photographs can uniquely determine their shape ... uncountably-infinite equivalence class". 알고리즘 무관의 기하학적 사실이다
2. **문제의 계보에 빈칸이 있다** — 5마디(space carving → MVS 가시성 → 불확실도 → NBV → shape completion) 어느 것도 "촬영 불변 + 채우기 비원" 조건을 다루지 않는다. 각 마디의 전제가 재촬영 가능 / 잔차 존재 / 채움 허용이다
3. **무대의 계보에서는 매 마디의 잔여물로만 이월됐다** — 3DGS §7.4 자인부터 PGSR §VI "관측이 없거나 부족한 영역"까지, 관측 결핍은 어느 마디의 "푼 것"에도 없고 전부 "남긴 것"에만 있다
4. **측정 자체가 없다** — GS 표면 재구성 평가에 구멍이 막혔는지 재는 표준 지표가 없다. **인접 분야에는 있는데(Sulzer 성분 수·경계 변, TopoSculpt Betti, High-Genus IR의 PH 채점) GS 평가가 안 쓴다.** PeerJ 서베이(2025)의 분류 축에도 관측 결핍이 없다

**반론 대비 (1-3 규율)**: "필요 없었던 것 아닌가"에 대한 답 — 응용 분야(치과·내시경)는 이 문제를 만나면 **카메라를 공동 안에 넣어 우회한다.** 필요가 없었던 게 아니라 **조건이 달랐다.** 외부 고정 카메라 무대에는 그 선택지가 없다.

## 3. 용어와 서술 규약 (발표 필수 — 어기면 즉시 반박당한다)

| 쓸 것 | 쓰지 말 것 | 이유 |
| --- | --- | --- |
| **self-occlusion**(원인) · **visibility function V(x,ω)**(양) · **visible view set / co-visibility**(뷰 집합) | 맨 **`view-dependent`** | NeRF·3DGS가 이 말을 **색에만** 쓴다 `[원문 확인]`. 청중이 specular로 알아듣는다. `view-dependent visibility`처럼 수식어를 붙인 복합어만 허용 |
| **낮은 조도 · ambient occlusion** (위치의 함수) | 어두운 내부를 **뷰 의존**으로 서술 | DTU는 **조명 고정 + 카메라 이동**이므로 어두움은 위치의 함수다 |
| 재구성 | 복원 | 08-18 확정 |
| 판별값·지표·confidence | 신호 | |

**발표 표준형**: "**self-occlusion이 내부 표면의 visible view set을 개구 방향으로 제한한다.**"

**주장 강도 규율**
- "학습 전"을 "학습 없이"로 번역하지 않는다. baseline은 그대로 전부 학습시키고 감독의 배분만 바꾼다
- 방법을 특정 baseline(MILo)에 국한된 것으로 서술하지 않는다
- **"외관이 기하를 보상한다는 것을 아무도 짚지 않았다"고 말하면 안 된다** — Mind the Gap(2607.01556) §5.2가 이미 명시했다. 우리 자리는 그 일반 명제가 아니라 **self-occlusion 축으로의 특정**이다

## 4. 가설 후보 (미확정 — "후보"라고 쓸 것)

**상위 진단**: **GS 계열에서 가시성은 독립적 증거로 작동하지 않는다.** 두 단계에서 이유가 다르다.

| 단계 | 왜 |
| --- | --- |
| **최적화 중** | 가시성이 기하에서 파생되어 **순환**한다 (기하 → transmittance → 감독 배분 → 기하). 얕고 잘못된 기하가 **자기 가시성을 스스로 정당화**한다 — 입구의 막이 안쪽을 가리고, 가려지니 감독에서 빠지고, 빠지니 막을 치울 이유가 없어진다 |
| **추출 중** | 가시성 항이 **아예 없다.** MILo Delaunay는 learnable SDF 부호에 위상을 맡긴다. 고전 Labatut은 가시성으로 사면체를 깎았다 |

**원전 관계**: NeRF++ §3 shape-radiance ambiguity를 **self-occlusion 축으로 확장**하는 형태다. 남의 명제를 빌려 타고 간다는 사실을 서술에 명시한다.

## 5. 방법 구상 (naive v0 — "구상 중"으로 표기)

**한 줄**: 카메라가 어떤 점을 봤으면 그 사이 선분은 비어 있다. 그 선분이 뚫는 면은 틀렸다.

- 재료는 **COLMAP이 이미 내놓는 것**뿐 — 카메라 포즈 + SfM 점 + track. 추가 촬영·학습·외부 모델 없음
- **가중치가 아니라 단언**이다. 감독을 약하게 주는 것으로는 구멍이 안 뚫린다 (없는 걸 더 없게 만드는 no-op). 자기 항을 갖고 부호를 뒤집어야 한다
- 3구역: **관측된 빈 공간**(단언해서 깎음) / **관측 안 됨**(경계 기하를 이어받아 연장하고 **열린 채로 표시**) / 그 외(건드리지 않음)

**차별 축 (질문 대비 필수)**
- **PGSR 대비**: "기존 가시성 처리는 자기 기하(렌더 깊이)에서 파생되므로 **순환 안**에 있다. 우리는 학습 이전에 확정된 SfM 관측에서 가져오므로 **순환 밖**에 있다."
- **AmbiSuR 대비**: "AmbiSuR는 관측이 있으나 **모호한** 구역에 학습 중 지표로 외부 prior를 투입한다. 우리는 관측 **증거 자체가 없는** 구역을 학습 전 촬영 기하로 지목하고, 외부 정보를 넣는 대신 관측된 경계의 기하를 이어받게 정칙화 체제를 바꾼다."

**자기모순 대비 — 반드시 갈라 쓸 것**: 우리는 구멍이 막히는 것을 문제 삼으면서 스스로 열린 mesh를 낸다. **MILo의 뚜껑은 개구부 입구에 있고 통과 광선에 모순되며 "여기 표면이 있다"고 틀리게 주장한다. 우리 경계는 내부 증거 전선에 있고 "여기부터 모른다"를 정직하게 표시한다.** 선례: Poisson 배포물의 SurfaceTrimmer가 non-watertight 생성을 공식 허용한다.

## 7. 나올 결과 (사전 등록됨 — 결과 자리 미리 잡아둘 것)

`design-2026-08-26-naive-v0.md` §10에 예측 P1~P5가 결과 보기 전에 등록돼 있다.

| 예측 | 슬라이드에서의 자리 |
| --- | --- |
| P1 관통부에 통과 광선 증거가 존재한다 | 증거 밀도 표 |
| P2 MILo·AmbiSuR에서 관통이 **막혀 있다** | 실패 실증 그림 (motivation 원판) |
| P3 carving하면 **열린다** | 전후 단면 비교 |
| P4 MILo 사면체 라벨링에 가시성 항이 **없다** | 원인 슬라이드 (코드 근거) |
| P5 **얇은 구조가 살아남는다** | 부작용 없음의 증거 |

**측정 지표** (Chamfer는 병기만, 주장 근거로 쓰지 않는다 — 관통이 닫혀도 국소 거리 오차로만 계상됨)
- **관통 깊이 비율 `d'/d`** — 뚜껑이면 0, 끝까지면 1
- **위상 지표** — 연결 성분 수, 경계 변 수, Betti/genus
- **오카빙 면적** — 삭제한 면 근처에 GT 점이 있는가. 합성에서 검출기 잡음 바닥 약 2% 확인

**정성 그림 규약**: 씬별 절단 평면을 **결과 보기 전에 등록**하고, `[GT, MILo, MILo+carve, AmbiSuR, AmbiSuR+carve]`를 같은 평면·같은 카메라로 단면 렌더. GT 열 필수 (덱 규칙 5-6).
