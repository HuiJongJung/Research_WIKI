# 260820 연구 전반 피드백

> 받은 내용을 보존하는 동결 기록. 대응은 progress-2026-08-20과 open-items에서.

## 받은 지적

1. **접근이 naive하고 scope가 넓다** — "SOTA로 hole 있는 object 복원이 잘 안 되더라 → 어떻게 해결하지"라는 문제 정의 자체가 그렇다.
2. **왜 생기는지의 원론적 이유를 찾지 못하고 추측만 한다** — 본인 추측 예: photometric상 hole이 까맣게 보이는데 그것이 진짜 hole인지 까만 표면인지 구분하지 못해 완전한 구멍을 뚫지 못하는 것 아닌가.
3. **GS mesh recon의 survey와 큰 문제의 계보를 먼저 따라가며** 지식을 쌓고 시각을 넓히는 것이 중요하다.
4. **명확하고 과하게 넓지 않은 문제를 잡고, 기존 기법들의 아이디어를 적당히 조합해 그것이 잘 된다는 증명**을 하는 편이 좋다.

## 위키 세션 1차 검토 (같은 날)

- 지적 1은 정당 — 단 발표된 버전이 내부 정리(깊이 비 변인·중간 지대·완결 구역)보다 낡았던 전달 문제도 겹침. 본인이 내부 정리를 아직 자기 언어로 소화하지 못한 상태.
- 지적 2의 본인 추측은 실패 해부도 6력 중 2번(뚜껑 최소값)과 동일 — 직관이 틀린 게 아니라 여섯 중 하나임을 몰랐던 것. **진짜 공백은 6력의 실측 검증 부재** → 해부도 실측 4건을 최우선으로 상향.
- 지적 4에 맞는 좁은 문제 후보 = **중간 지대(회복 가능 전선)**: "얕은 개구는 회복 가능한데도(AmbiSuR 존재 증명) base가 메운다 — 학습 전 촬영 기하로 지목해 살린다." 기존 아이디어 조합(PGSR 게이트를 학습 전으로 + CDGS류 가중을 기하로 + clone 억제)이며 성공 기준 판정 가능. **채택 여부는 사용자 결정 대기.**
- 지적 3의 실행형 = 계보 지도 조립(Q-28) + 그 위에서 1군 읽기.
