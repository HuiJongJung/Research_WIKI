# 진행 기록 2026-08-19

> 일자별 이력. 현재 상태는 `research-status.md`, 항목별 현황은 `open-items.md`.
>
> 오늘의 내용: 0818 세미나 피드백에 따른 방향 전환 확정과 3분배(조사·본인·실험).

## 방향 전환 (사용자 확정)

1. **배경 재구성 폐기.** GS용 데이터(중앙 물체 360도)에서 배경을 만드는 것은 너무 specific — 배경이 목표면 배경용 데이터로 하면 되고, 디지털 트윈도 GS용 데이터로 배경을 만들지 않는다.
2. **새 표적 = hole 있는 단일 오브젝트의 mesh 품질.** SOTA가 실패하는 특정 케이스(내부·오목·구멍)를 잡아 motivation을 다시 세운다.
3. **MILo 비고집.** 어떤 기법에든 붙는 독립 모듈로. "GS 개선 = mesh 개선"을 전제하지 않고 그 연결 자체를 실측으로 증명한다.
4. **confidence field 다채널 재설계 검토** — 각도 + 거리·빈도·가시성. threshold는 learnable 포함 검토, 각도 기준은 근거 필수.
5. 데이터셋은 기존 데이터셋에 오브젝트 추가도 허용됨을 확인받음 (부담 완화).

## 3분배

- **조사 (Q-14~Q-21)**: 단일 물체 SOTA와 실패 사례 / hole·seg·바이오 데이터셋 / densification 과잉 선행 / pcd→mesh GT 선례 / CAD 지표·FID / self-occlusion 판별 선행 / seg 기반 평가 실체 / GS→mesh 연결 선행
- **본인 (M1~M7)**: motivation 확정(R1 대기) → 무대·SOTA 확정 → field 재설계 판정 → MILo 분리 인터페이스 → DTU65 뒤통수 관측
- **실험 (X1~X7)**: 즉시 가능 5건(물체 무대 발화 확인·track 가시성 채널·GS→mesh 연결 실측·뒤통수 렌더·threshold 스윕), M 판정 후 2건(간단 hole 씬·타 기법 부착)

**순서: 조사 먼저.** M1~M5가 전부 조사 회수에 의존한다. X1~X5는 병행 가능하나 사용자 결정으로 조사 선행.

## Q-14~Q-21 회수 판정 6건 (08-19)

1. **Gaussian Sculpting(arXiv 2608.10602v1) = 경쟁 후보 등재, novelty 위협 아님.** 무대·지표·문제의식 최근접이나 기전이 정반대(학습 중 SDF 최적화 vs 학습 전 촬영 기하 진단). 이득 둘 — mesh 자체 품질 지표의 인용 선례, "limited viewpoints" 문제 인식의 최신 근거. 공개 8일차 v1이므로 코드·판본 추적 등록(Q-23).
2. **M1 구조 채택: "자인의 부재 = 측정의 부재."** 배경 무대의 측정 공백 서사가 새 무대로 이식된다(DTU ObsMask가 관측 표면만 채점 → hole·오목은 재지 않음 → 자인도 없음). 서술 규율: "아무도 인정 안 함" 금지, "자인은 관측 결핍 일반까지 존재하며 hole·오목·내부는 측정되지 않는다"가 정확. 인용+실측 시연 결합 필수 — X4(뒤통수 렌더)가 motivation 그림으로 승격. PGSR ablation 0.52→0.28 인용 가능. 출처 미특정 오목 문장 사용 금지(원전 특정 전).
3. **M2 무대: 조합안 보류, 조건 완화 재조사(Q-22).** 사용자 기준 — hole 오브젝트 필수, GT mesh 가산점, seg·바이오 비필수. "교집합 부재→조합 불가피" 프레임은 과했음.
4. **평가 설계: 방향 채택.** 관례 지표 첫 열 + 부위별 채점(원문 확인 선행) + CAD 지표(선례 확보) + 위상 지표. FID 주 지표 기각.
5. **lever④′ First-to-X 등록**: "학습 전 촬영 기하 판별값으로 densification 조향 — 사례 없음." 인접 3종(CoMe·Expo-GS·LeGS) 병기 조건. LeGS는 arXiv로만.
6. **등재 2건**: VAD-GS 경쟁 표(track 가시성 인접 선행, 용도 상이). 2DGS p.2 "inherently unconstrained nature" 용어 은행 — under-constrained의 최근접 원문 앵커.

**남은 M 작업**: M1(motivation 문장 확정 — 잠정판을 research-status 1절에 게시), M2(무대 — Q-22 대기), M4(field 재설계 — X1·X2 실측 대기).

## baseline sweep 계획 확정 (사용자 제안)

**새 무대 후보들에 MILo·AmbiSuR 공통 재구성을 돌린다** (+ Gaussian Sculpting은 코드 확인 후 조건부). 역할 셋: ① motivation 실측 시연(M1이 요구하는 그 실측) ② 무대 선별(실패가 안 보이는 씬은 부적합 — 그것도 결과) ③ 나중에 ours를 얹을 baseline.

**2단계 구성**: 1단계 = DTU scan65 즉시(학습 재사용, hole 부위 렌더 + **GT hole 커버리지 확인** + 발화 확인). 2단계 = Q-22 회수 후 후보 3~5개 셋업·sweep.

**규율 둘**: 씬 선정 기준(hole 존재 + GT 존재 + 표준 촬영)을 결과 보기 전에 등록 — 체리피킹 방어. GT hole 커버리지를 sweep 전에 확인 — Ignatius의 교훈(GT 스캐너도 밖에서 찍는다) 재적용. 커버리지가 없으면 hole 정량 채점이 원리적으로 불가하며 그 사실 자체가 측정 공백 서사의 새 무대 판이 된다.

## M2 판정 — 무대 확정 (Q-22·Q-23 회수)

**1군**: DTU scan65(주 판정 — 석고라 반사 교란 없음, 학습 기존 보유) + **scan37**(시연·진단 관찰 — RaDe-GS가 원문 명시한 실패 씬. 반사·hole 겹침이므로 개입 판정에서 제외하되, field가 링 내부(예측해야 함)와 반사면(예측하지 않아야 함)을 가르는지의 스코프 관찰 포인트로 역이용). **scan37 발견으로 DTU 하나에서 hole 2종 성립 — 추가 데이터셋 없이 시작 가능.**
**2군**: Thingi10K 선별 2~3개 (genus 통계 선별 = 자의성 차단, 설계 mesh = GT 논란 원천 차단). 선별 기준 사전 등록 조건.
**3군 (조건부)**: OmniObject3D teapot·kennel — 라이선스 확인 후. Gaussian Sculpting 코드 미공개이므로 같은 무대 수치가 유일한 직접 비교 수단.
**보류**: MedShapeNet(바이오 비필수 강등+품목 미확인), MobileBrick(hole 근거 2차 자료뿐), Stanford(서사 재료), NeRF-Synthetic(삽입 경로 대기).

**Q-23 반영**: ① 오목 자인 원전 = SatSplat §4.5 (사용 금지 해제). 덤 — 원인을 **2DGS 평면 primitive 가정**으로 지목하는 기전 서술 포함, AmbiSuR 기반 PGSR도 평면 계열이므로 base 다양화 시 primitive 유형 축(3D 대 평면) 명시 조건 등록. ② NPP 결손 부위 규칙 verbatim 확보 → 평가 설계 편입. ③ Gaussian Sculpting 코드 미공개 — 비교군 보류 유지. ④ **LeGS = ICML 2026 확정 + 코드 공개 — 본 문서 앞선 판정 5번의 "arXiv로만" 표기를 해제하고 ICML 2026으로 인용한다.**

research-status 7절을 hole 무대판으로 재작성했다. 1절은 잠정판 유지(M1 = 사용자 확정만 남음).

## scan37 근거 표기 정정 (사용자 질문에서, 위키 직접 검증)

사용자가 "scan37이 검색해도 안 나온다"고 지적해 원문을 직접 확인했다.

- **RaDe-GS 원문에는 scan 번호가 없다.** "the Metal Scissor of DTU dataset (shown in Figure 7)"까지이며 표·캡션 어디에도 번호-물체 매핑이 없다. 조사 세션이 번호 매핑을 `[원문 확인]` 태그 안에 묶은 것은 **엄밀성 규칙 위반 사례**(2차 매핑을 원문 태그로 포장)로 기록한다.
- **매핑 자체는 맞다.** 독립 논문 복수가 scan37을 가위로 명시한다 — "scissors' handles in Scan37"(arXiv 2408.02079), "many other methods tend to fuse together in Scan37". scan37은 표준 15스캔 목록(24·37·40·55·63·65·69·83·97·105·106·110·114·118·122)에 포함.
- **덤**: "fuse together in Scan37" = 가위 링이 붙어버리는 실패 = **hole 닫힘의 직접 문헌 근거.** RaDe-GS의 반사 자인보다 표적에 더 직접적이다. 조사 세션에 원문 확인 후 인용 승격 요청 (Q-23 후속).
- DTU는 물체 이름 카탈로그가 공식으로 없어 번호 검색으로 실물이 안 나온다. 실물 확정은 sweep 프롬프트의 "입력 이미지 1장 선회신" 관문이 담당한다.
