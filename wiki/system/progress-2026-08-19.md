# 진행 기록 2026-08-19

> 일자별 이력. 현재 상태는 `research-status.md`, 항목별 현황은 `open-items.md`.
>
> 오늘의 내용: 0818 세미나 피드백에 따른 방향 전환 확정과 3분배(조사·본인·실험).

## 방향 전환 (사용자 확정)

1. **배경 재구성 폐기.** GS용 데이터(중앙 물체 360도)에서 배경을 만드는 것은 너무 specific — 배경이 목표면 배경용 데이터로 하면 되고, 디지털 트윈도 GS용 데이터로 배경을 만들지 않는다.
2. **새 표적 = hole 있는 단일 오브젝트의 mesh 품질.** SOTA가 실패하는 특정 케이스(내부·오목·구멍)를 잡아 motivation을 다시 세운다.
3. **MILo 비고집.** 어떤 기법에든 붙는 독립 모듈로. "GS 개선 = mesh 개선"을 전제하지 않고 그 연결 자체를 실측으로 증명한다.
4. **confidence field 다채널 재설계 검토** — 각도 + 거리·빈도·가시성. threshold는 learnable 포함 검토, 각도 기준은 근거 필수.
5. 데이터셋은 기존 데이터셋에 오브젝트 추가도 허용됨을 확인받음 (부담 완화).

## 3분배

- **조사 (Q-14~Q-21)**: 단일 물체 SOTA와 실패 사례 / hole·seg·바이오 데이터셋 / densification 과잉 선행 / pcd→mesh GT 선례 / CAD 지표·FID / self-occlusion 판별 선행 / seg 기반 평가 실체 / GS→mesh 연결 선행
- **본인 (M1~M7)**: motivation 확정(R1 대기) → 무대·SOTA 확정 → field 재설계 판정 → MILo 분리 인터페이스 → DTU65 뒤통수 관측
- **실험 (X1~X7)**: 즉시 가능 5건(물체 무대 발화 확인·track 가시성 채널·GS→mesh 연결 실측·뒤통수 렌더·threshold 스윕), M 판정 후 2건(간단 hole 씬·타 기법 부착)

**순서: 조사 먼저.** M1~M5가 전부 조사 회수에 의존한다. X1~X5는 병행 가능하나 사용자 결정으로 조사 선행.

## Q-14~Q-21 회수 판정 6건 (08-19)

1. **Gaussian Sculpting(arXiv 2608.10602v1) = 경쟁 후보 등재, novelty 위협 아님.** 무대·지표·문제의식 최근접이나 기전이 정반대(학습 중 SDF 최적화 vs 학습 전 촬영 기하 진단). 이득 둘 — mesh 자체 품질 지표의 인용 선례, "limited viewpoints" 문제 인식의 최신 근거. 공개 8일차 v1이므로 코드·판본 추적 등록(Q-23).
2. **M1 구조 채택: "자인의 부재 = 측정의 부재."** 배경 무대의 측정 공백 서사가 새 무대로 이식된다(DTU ObsMask가 관측 표면만 채점 → hole·오목은 재지 않음 → 자인도 없음). 서술 규율: "아무도 인정 안 함" 금지, "자인은 관측 결핍 일반까지 존재하며 hole·오목·내부는 측정되지 않는다"가 정확. 인용+실측 시연 결합 필수 — X4(뒤통수 렌더)가 motivation 그림으로 승격. PGSR ablation 0.52→0.28 인용 가능. 출처 미특정 오목 문장 사용 금지(원전 특정 전).
3. **M2 무대: 조합안 보류, 조건 완화 재조사(Q-22).** 사용자 기준 — hole 오브젝트 필수, GT mesh 가산점, seg·바이오 비필수. "교집합 부재→조합 불가피" 프레임은 과했음.
4. **평가 설계: 방향 채택.** 관례 지표 첫 열 + 부위별 채점(원문 확인 선행) + CAD 지표(선례 확보) + 위상 지표. FID 주 지표 기각.
5. **lever④′ First-to-X 등록**: "학습 전 촬영 기하 판별값으로 densification 조향 — 사례 없음." 인접 3종(CoMe·Expo-GS·LeGS) 병기 조건. LeGS는 arXiv로만.
6. **등재 2건**: VAD-GS 경쟁 표(track 가시성 인접 선행, 용도 상이). 2DGS p.2 "inherently unconstrained nature" 용어 은행 — under-constrained의 최근접 원문 앵커.

**남은 M 작업**: M1(motivation 문장 확정 — 잠정판을 research-status 1절에 게시), M2(무대 — Q-22 대기), M4(field 재설계 — X1·X2 실측 대기).

## baseline sweep 계획 확정 (사용자 제안)

**새 무대 후보들에 MILo·AmbiSuR 공통 재구성을 돌린다** (+ Gaussian Sculpting은 코드 확인 후 조건부). 역할 셋: ① motivation 실측 시연(M1이 요구하는 그 실측) ② 무대 선별(실패가 안 보이는 씬은 부적합 — 그것도 결과) ③ 나중에 ours를 얹을 baseline.

**2단계 구성**: 1단계 = DTU scan65 즉시(학습 재사용, hole 부위 렌더 + **GT hole 커버리지 확인** + 발화 확인). 2단계 = Q-22 회수 후 후보 3~5개 셋업·sweep.

**규율 둘**: 씬 선정 기준(hole 존재 + GT 존재 + 표준 촬영)을 결과 보기 전에 등록 — 체리피킹 방어. GT hole 커버리지를 sweep 전에 확인 — Ignatius의 교훈(GT 스캐너도 밖에서 찍는다) 재적용. 커버리지가 없으면 hole 정량 채점이 원리적으로 불가하며 그 사실 자체가 측정 공백 서사의 새 무대 판이 된다.

**1군**: DTU scan65(주 판정 — 석고라 반사 교란 없음, 학습 기존 보유) + **scan37**(시연·진단 관찰 — RaDe-GS가 원문 명시한 실패 씬. 반사·hole 겹침이므로 개입 판정에서 제외하되, field가 링 내부(예측해야 함)와 반사면(예측하지 않아야 함)을 가르는지의 스코프 관찰 포인트로 역이용). **scan37 발견으로 DTU 하나에서 hole 2종 성립 — 추가 데이터셋 없이 시작 가능.**

## scan37 근거 표기 정정 (사용자 질문에서, 위키 직접 검증)

사용자가 "scan37이 검색해도 안 나온다"고 지적해 원문을 직접 확인했다.

- **RaDe-GS 원문에는 scan 번호가 없다.** "the Metal Scissor of DTU dataset (shown in Figure 7)"까지이며 표·캡션 어디에도 번호-물체 매핑이 없다. 조사 세션이 번호 매핑을 `[원문 확인]` 태그 안에 묶은 것은 **엄밀성 규칙 위반 사례**(2차 매핑을 원문 태그로 포장)로 기록한다.
- **매핑 자체는 맞다.** 독립 논문 복수가 scan37을 가위로 명시한다 — "scissors' handles in Scan37"(arXiv 2408.02079), "many other methods tend to fuse together in Scan37". scan37은 표준 15스캔 목록(24·37·40·55·63·65·69·83·97·105·106·110·114·118·122)에 포함.
- **덤**: "fuse together in Scan37" = 가위 링이 붙어버리는 실패 = **hole 닫힘의 직접 문헌 근거.** RaDe-GS의 반사 자인보다 표적에 더 직접적이다. 조사 세션에 원문 확인 후 인용 승격 요청 (Q-23 후속).
- DTU는 물체 이름 카탈로그가 공식으로 없어 번호 검색으로 실물이 안 나온다. 실물 확정은 sweep 프롬프트의 "입력 이미지 1장 선회신" 관문이 담당한다.

## 표적 정의 정밀화 (사용자) — "깊은 구멍"으로 좁힘, scan37 제외

**hole의 정의를 관통 링이 아니라 깊은 오목·관·내부 공간으로 좁힌다** (파이프 내부, 컵·화병 안쪽, 개구로만 보이는 공동). 핵심 변수 = 깊이 대 개구 비.

**근거 — 두 실패는 기전이 다르다**: 관통 링(가위)의 실패는 위상 보존(붙어버림)이고 관측 결핍이 아니다. 깊은 구멍의 실패는 내부 벽이 개구를 통해서만·스치는 각으로만 보이는 관측 결핍이며 **우리 field가 예측해야 정상인 바로 그것**이다.

**이론 고리 (설계 자산으로 등록)**: 관 내부 깊이 d, 개구 반지름 r인 점의 관측 시선 원뿔은 기하학적으로 최대 **2·atan(r/d)**로 제한된다. 즉 spread가 깊이에 대해 결정론적으로 감소 — "field가 관 내부를 위험으로 짚는다"가 실험 전에 수학으로 선다. 관통 링에는 이런 고리가 없다.

**M2 수정**: scan37 제외("fuse together" 재료는 위상 실패 기록으로만 보관), scan65 유지(안와·비강 = 깊은 오목), OmniObject3D kennel 가치 상승, **Thingi10K genus 선별 기준 부적합 판정** — 막힌 깊은 구멍은 genus 0이라 위상 필터로 못 고른다. 깊이 대 개구 비 기준으로 교체하되 측도는 Q-24 조사 대상.

**Q-24 등록**: 파이프·관 데이터셋(Q-09 잔여의 PipeForge3D 정면 승격), 기존 데이터셋 내 깊은-구멍 물체 재선별, 깊이 정량 측도 선례, 깊은 내부 recon 선행. 실험 세션에는 scan37 셋업 중단과 scan65 뷰 우선순위(안와·비강 클로즈업) 전달.

## Q-24 회수 판정 — 보어 블록 채택, C3VD 제외, 무대 구성이 기여 후보로

**"찾지 못함" 둘이 실질 수확**: 외부 궤도 + 개구 제한 관측으로 깊은 내부를 표적한 GS/NeRF 선행 없음, AO/SDF 선별로 벤치마크를 구성한 사례 없음 → **무대 구성 자체가 기여가 될 수 있는 빈자리 확인.** PipeForge3D는 부적합(생성기이며 관 외부 표면 대상), 파이프 실사 데이터셋은 없음.

**판정 1 — 깊이 비 스펙트럼 채택, 공급원은 직접 제작 주력.** 3층 무대:
- **① 보어 블록 (주 판정)**: 무광 텍스처 블록 하나에 같은 지름 r, 깊이 d/r = 0.5/1/2/3/5의 막힌 구멍 5개. 전체 궤도(BlenderNeRF COS), GT = 설계 mesh. **한 씬 안에서 깊이 스윕** — 씬 간 교란 원천 제거. **사전 등록 예측: 보어 내부 오차는 d/r에 증가, field conf는 2·atan(r/d) 이론 곡선을 따라 감소, 두 곡선이 같이 움직인다 — 새 무대판 H2이며 이론 곡선이 있어 구판보다 강함**
- ② AO 선별 자연 물체 (일반화): Thingi10K 태그 검색 + AO 로컬 계산. **AO 선별 기준은 선례 부재로 기여 후보 승격**
- ③ 실사 앵커: scan65 안와·비강 + OmniObject3D kennel

**판정 2 — C3VD 제외, related work 한 줄.** 카메라가 관 안에 들어가는 관측 기하라 명제를 시험하지 않음. 대비 논거로 사용: "카메라를 내부에 넣을 수 있으면 문제가 사라진다(내시경 계열) — 본 연구는 그럴 수 없는 경우다."

**판정 3 — OpenXLab 등록 진행** (실험 세션). 라이선스 반복 미해결 종결 + kennel·mug·vase 확인.

**M4 연결 승인 — AO를 GT측 난이도 라벨로.** field 예측(카메라 기하) ↔ AO(형상 기하) ↔ 실측 오차의 **3자 검증 구조**. field가 AO를 따라가면 판별값 타당성이 GT 없이 서고, 오차까지 따라가면 H2 완성.

**잔여**: VolFill 가시성 분해 채점의 원문 확인(2차 자료 상태 — Q-21 부위별 채점과 결합 검토), OmniObject3D 카테고리 확인은 등록 후 실험 세션이.

## 실험 매트릭스 확정 (사용자 결정)

라운드 0 = scan65 렌더(기존 학습 재사용). 라운드 1 = 보어 블록 × **3모델(MILo·AmbiSuR·PGSR)**. 라운드 2 = Thingi10K 선택분 × 2모델. 라운드 3 = OmniObject3D × 2모델. **PGSR은 핵심 씬(scan65·보어 블록) 한정 3번째 모델** — occlusion 추정(학습 중)의 성패가 우리 학습-전 예측의 직접 대조가 된다. scan65에는 PGSR 학습 1런 추가 필요.

읽기 계획도 확정 — 1묶음(2DGS→PGSR→Gaussian Sculpting, 챙길 요소 명세는 my-tasks) 후 M1 뼈대 완성, 2묶음(CDGS·VAD-GS) 방어용, 3묶음(Smith·D&S) M4 착수 시.

## 실행 순서 최종 확정 (사용자)

1. **씬 선정** — 시트 3장 보고 데이터셋 3개(DTU·Thingi10K·OmniObject3D)에서 **각 1씬씩** 사용자가 직접
2. **MILo + AmbiSuR로 각 씬 sweep** (총 6런)
3. 그 사이 **PGSR 셋업 병행 + 사용자는 1묶음 논문 읽기** (2DGS→PGSR→Gaussian Sculpting)
4. sweep 끝나면 **PGSR 런은 마지막에** (핵심 씬 한정 원칙 유지)
5. 결과 + 읽기를 합쳐 **confidence map 재설계 아이디어 도출** (M4로 수렴)

보어 블록 제작은 GPU 불요 별도 트랙으로 병행 유지 (2·atan(r/d) field 검증은 학습 없이 가능).

## 주장 구조 정리 — "GS 개선 = mesh 개선" 등식은 지지 않는다 (사용자 논의)

C군 피드백의 해법을 등식 증명이 아니라 **주장을 mesh에서 직접 세우는 것**으로 확정한다. 평가를 처음부터 mesh 지표(Chamfer·내각·sliver·위상)에서 하면 GS quality는 언급할 필요 없는 중간 변수다. 그 등식은 참도 아니다 — CoMe Table 5(primitive↑ F1↓)와 Desiatov & Sattler(시각 불변·기하 개선)가 비단조를 이미 보였다.

**대신 MILo를 벗어나는 순간 생기는 의무**: 비 in-loop 기법(사후 TSDF 추출)에서는 개입→Gaussian→렌더 깊이→TSDF→mesh로 경로가 길어 효과가 추출 단계에서 씻길 수 있다. **"개입 효과가 추출을 살아남는다"를 비 in-loop 최소 1기법에서 실측**하는 것이 일반성 주장(D4)의 가격이며, X7의 존재 이유다.

**PGSR 읽기 목표 추가**: 기존(occlusion 기전)에 더해 **렌더 깊이→TSDF 경로의 구조** — 우리 개입의 부착점과 생존 경로. PGSR이 비 in-loop 시험대 그 자체다.

## Confidence Field v2 초안 등록 (사용자 구상 기반)

사용자 요구 둘(self-occlusion 판별 필수 / 정보 없는 곳은 artifact 대신 평평한 완결)을 축으로 v2 초안을 작성했다 — `design-2026-08-19-object-field-draft.md`. 핵심: **강건 폭 공식 하나를 두 카메라 집합(프러스텀 전체 = 상한 / 점 관측 합집합 = 가림 반영)에 적용**해 spread_pose·spread_vis 두 채널을 만들고, 3상태(WELL/DEGRADED/UNSUPPORTED)로 **표면을 재구성 구역과 완결 구역으로 학습 전에 가른다.** UNSUPPORTED(프러스텀상 보이는데 매칭 0 = self-occluded)가 완결 구역이며, 목표를 복원이 아니라 최소 피해 완결+표시로 둔다 — D6-ⓓ의 발전형이자 수렴 명제와 정합. count_gap 금지와의 관계(차이→각도 폭, 점 단위→합집합)를 해소 논거로 명시했고 충분성은 X2가 판정. 확정은 sweep+PGSR 읽기 후 M4.
