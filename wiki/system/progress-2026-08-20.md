## 회수 — DTU 구멍 씬 2개 정성 (MILo base / AmbiSuR, 레버 없음)

패턴: **깊이가 성패를 가른다.** 얕은 개구(비강·관골궁)는 AmbiSuR가 살리고 MILo는 실패(메움·너덜·상악에 가짜 구멍). 깊은 공동(안와·눈송이 관통·개구부)은 **둘 다** 메운다 — MILo는 뭉개고 AmbiSuR는 매끈하게 덮는다.

무대 사실 둘: DTU 124스캔 전수 확인 결과 단일 물체+구멍은 65·69뿐 — **DTU는 새 표적의 본 무대가 아니다** (65·69는 실사 앵커로만). DTU GT는 구조광이라 공동 내부가 기준에 없을 가능성 — 구멍을 메워도 Chamfer 벌점이 거의 없는 **정량 타당성 문제**.

## 판정 — 관측의 재해석: "중간 지대"가 실재한다

| 지대 | 실측 | 의미 |
| --- | --- | --- |
| 얕은 개구 | MILo 실패 / AmbiSuR 성공 | **감독 품질이 성패를 가르는 지대 = 차등 개입의 leverage** |
| 깊은 공동 | 둘 다 실패 | 어떤 감독도 못 살림 = **수렴 명제의 물체 무대 재현** |

**field v2의 B/C 구분에 경험적 의미 부여**: B(재구성 구역) = 회복 가능 전선, C(완결 구역) = 회복 불능 지대. 두 임계가 임의 구분이 아니라 "방법들이 갈리는 선"과 "방법들이 다 같이 죽는 선"이다.

**실패 방식 차이의 함의**: AmbiSuR의 매끈한 덮음은 C 구역이 목표하는 완결과 겉모습이 같다 → C에서 우리 차별점은 닫기 자체가 아니라 **표시 + 닫는 위치의 통제**로 좁혀진다. MILo의 너덜·가짜 구멍이 clone 억제·평탄화의 1차 표적.

## 질문 3건 답

1. **"깊이가 가른다" 승격 보류** (n=2 정성). 승격 조건 = shofar/보어 블록(메우면 벌점이 드는 무대) 정량 재현. **조작적 정의 = spread_vis** (관측의 깊이 — 카메라가 들여다보면 깊어도 안 깊음), 2·atan(r/d)는 관 기하 이론형, AO는 GT측 대조 라벨.
2. **stl 확인 즉시 진행.** 예측 등록: 안와·눈사람 내부에 GT 점 없음/희박 → Ignatius GT 발견의 물체 무대 재현, "구멍을 메워도 벌점이 없다"가 측정 공백 서사의 새 판이 된다.
3. **개입 대상은 구역별로 다르다**: B = "메움"(살릴 수 있는데 닫힘 — 감독 강화가 답, AmbiSuR가 가능성 증명), C = "너덜·가짜 구멍"(매끈한 덮음은 목표에 가까움 — 표시만 추가).

## SOTA 지위 판정과 실패 기전 분해 (사용자 질문에서)

**AmbiSuR의 지위를 축으로 가른다**: 일반 단일 물체 축에서는 실행 가능 최강(Q-14)이 맞다. **hole 축에는 현직 SOTA가 없다** — 아무도 재지 않으므로 순위가 존재하지 않는다. AmbiSuR는 "일반 축 최강자도 이렇다"를 보여주는 대조이며, 서사는 "hole SOTA를 이긴다"가 아니라 **"hole에는 SOTA라 할 것이 없다"**다.

**깊은 구멍 실패는 과잉결정** — 여섯 힘이 전부 닫는 쪽:
1. 관측 원뿔 폐쇄 (2·atan(r/d), 기하학)
2. photometric의 "뚜껑 최소값" — 어두운 내부는 어두운 뚜껑으로 거의 동일하게 설명됨 (추론)
3. 정규화가 닫기를 보상 — 평면성·매끈함에 뚜껑은 상, 테두리는 벌 (SatSplat §4.5 원문, PGSR 평면 primitive)
4. 가림 게이트 잠김 루프 (사전 등록 예측, AmbiSuR 상속 여부 [코드 확인 필요])
5. 초기화·densification 질감 편향 (2DGS §7 원문, 내부 SfM 점 부재)
6. 단안 prior의 다리 놓기 — DA3가 구멍 위를 이어버릴 가능성 [추정, 실측 가능]

**AmbiSuR 도구의 사정거리**: I_SH는 시점 의존적 색 모호함을 탐지하는데 구멍 내부는 시점 일관적(어디서나 어두움) — 발화할 이유가 없다. 관측 결핍은 그들이 정의한 문제 밖이다. 사각지대 논거의 물체 무대판.

**실패 해부도 실측 4건 등록** (전부 저비용): (a) I_SH가 구멍 내부에서 조용한가 (b) DA3 깊이가 scan69 구멍을 잇는가 (c) PGSR 게이트 가중 ~0 (기등록) (d) 구멍 내부 SfM 점 밀도. 확인되면 motivation이 "아무도 안 잰다"에서 "왜 못 하는지 힘별로 안다"로 격상된다.

## 표현 층 재검토와 GW 진단 구상 (사용자 논의)

**Q1 답 확정**: field는 학습 전 1회 생성·불변, 학습 중에는 조회만 (가중·게이트). PGSR류 자기참조 게이트와의 구분점.

**voxel 해상도 우려의 판정**: 절반 오해(기하는 Gaussian이 만들고 field는 배분만 — 개입 입도는 픽셀·Gaussian 단위), 절반 진짜(96³ 수축 격자는 무한 배경용이라 물체엔 낭비). **해소 방향: voxel은 방법이 아니라 캐시다** — conf(x)는 카메라에서 정의된 연속 함수이며 물체 규모(카메라 ~100대)에서는 Gaussian 위치 직접 평가도 공짜 수준. 물체 무대 구현 = 수축 폐기 + bbox 격자 또는 per-Gaussian 정확 평가. v2 초안에 반영. 남는 병목은 구멍 안 SfM 점 희소인데 이는 해상도 문제가 아니라 정보 부재이며, 점 부재 자체가 C 구역 판정 신호라 설계상 자연 처리.

**GW 진단 구상 (사용자 발의)**: 자전거 살(가는 고체, 잘 보임, 표현 한계)과 깊은 구멍(빈 공간, 안 보임, 관측 한계)은 반대 문제다. GW를 scan69에 돌리면 실패의 종류가 갈린다 — 눈송이 관통을 열면 표현 한계(GW 계열의 몫), 못 열면 관측 한계(우리 몫), 안와는 GW도 못 열 것으로 예측. **"표현 한계와 관측 한계는 다른 실패"의 실측 분리 = 스코프 문장의 그림.** Q-26(GW 코드·셋업 확인) 회수 후 진단 런 여부 결정.
