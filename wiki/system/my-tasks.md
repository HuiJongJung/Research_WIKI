## 1. M1 — motivation 4단 뼈대 다듬기 [최우선. 뼈대는 지금, 확정은 실측 후]

**첫 문장 "SOTA가 못 만든다"는 인용으로 채울 수 없다** — SOTA들이 hole 실패를 자인하지 않기 때문(측정을 안 하므로, Q-14). 그러므로 ①은 우리 그림이어야 하고, scan65 안와·비강 렌더와 보어 블록 결과가 그것이다. **"못한다" 자체도 아직 우리 실측이 없음을 인지** — 충분한 깊이에서의 실패는 기하학적으로 보장되나(관측 원뿔 → 0), 실측이 답하는 것은 "실패 시작 깊이가 실용 범위 안인가"다.

4단 뼈대 (②③④는 재료 완비, ①만 실험 대기):
1. **SOTA는 깊은 구멍 내부를 재구성하지 못한다** — [그림: scan65 안와 / 보어 블록 스윕] ← 실험 대기
2. **아무도 그 실패를 모른다** — ObsMask가 채점하지 않아 지표는 멀쩡하고 자인도 없다
3. **실패는 촬영 기하에서 예측 가능하다** — 관측 원뿔 ≤ 2·atan(r/d)
4. **학습 전에 짚고 차등 배분한다**

- [ ] 뼈대 ②③④를 본인 문장으로 지금 다듬기
- [ ] scan65 렌더 도착 → ① 채우고 실사 성립 확인
- [ ] 보어 블록 도착 → 실패 경계 숫자 확정 → M1 최종

## 2. 읽기 (08-19 재편 — 새 무대 계보 중심)

**1군 (이번 주, 한 묶음): 새 무대의 뼈대. M1 문장은 이 셋 읽으며 같이 여물인다**

- [ ] 2DGS **보충 발췌만 (30분)** — 기존 정리가 방법·정규화·한계를 이미 커버함(08-19 확인). 남은 두 조각: ① **mesh 추출 절차**(렌더 깊이 → TSDF — in-loop와 정반대 경로의 기준점, GS→mesh 연결 논의의 틀) ② **정규화 두 항의 실제 식**(depth distortion·normal consistency — 우리 가중 모듈이 타 기법에 꽂힐 부착점의 원형)
- [ ] **PGSR** — ★실질 1순위 (2DGS가 보충 발췌로 축소되면서). occlusion 추정 하나로 F1 절반(0.52↔0.28)을 얻음 = **우리 가시성 채널의 "학습 중" 대응물.** AmbiSuR의 기반이자 **비 in-loop 시험대 그 자체**(렌더 깊이→TSDF 사후 추출). 목표: ① occlusion 추정 기전 정확히 ② **렌더 깊이→TSDF 경로 구조** — 우리 개입의 부착점과 추출 생존 경로 (X7·일반성 주장의 전제)
- [ ] **Gaussian Sculpting** (arXiv 2608.10602) — 최근접 경쟁, "뭐가 다르냐" 질문 필수 대비. mesh 품질 지표(내각·sliver)의 계산 방식도 우리 채택 선례. 목표: 방법 + 지표 정의 + 무엇을 못 하는지

**2군 (다음): 인접 선행 방어**

- [ ] **CDGS** — 가장 가까운 인접 선행(학습 전 confidence로 깊이 감독 가중). 차별화 문장을 본인 입으로
- [ ] **VAD-GS** — track 가시성 + densification 조향, 우리 가시성 채널·clone 억제 둘 다에 인접

**3군 (M4 착수 시): 설계 입력**

- [ ] Desiatov & Sattler — 기하≠시각의 실측 선례
- RaDe-GS 훑기만 (MILo 래스터라이저 — 구조만), Rumpler 목표 한정

**읽지 않는다**: hole 전용 논문(존재하지 않음 — Q-24 확인), GOF·GeoSVR·GVGS 정독(자인·수치는 위키에), AREA3D·InstantSplat(위협 분류 종결). Expo-GS는 선택 유지
