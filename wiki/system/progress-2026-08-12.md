## 회수된 결과 (실험 세션, 관측 단계)

**DTU scan65 (Chamfer ↓)**: base 0.752 / global 0.757 / ours 0.768 / ambisur 0.488. global이 base와 목적함수가 같아 0.005가 재현 오차 바닥이고, ours의 +0.016은 그 3.2배 — **물체 씬에서 개입은 실제로 해롭다.** field의 극단 저각도 비율이 5.9%로 Ignatius(4.9%)와 같은데 그 저각도가 배경·테이블(채점 밖)에 있음 — 위양성.

**T&T Ignatius (F-score ↑)**: 총량 고정판 base 0.7631 / global 0.7644 / ours 0.7704 / ambisur 0.7729. **가산형**: global 0.7379(−0.025) / ours 0.7708(+0.008). 발화율 0.18~0.80(평균 0.5 — 기준각이 표면 중앙값이라 정의상 표면 절반 대상).

## 결정 1 — 주장 (A) 배치 효과: 문구 축소 후 rep2 조건부 승격

주장을 **"같은 총량을 균일 추가하면 해롭고(−0.025), 차등 배치하면 해롭지 않다"**로 좁힌다. ours가 base를 이긴다(+0.0077)는 주장에서 뺀다 — 단일 런이고 노이즈 바닥이 없다. 이렇게 좁히면 global_rep2 재현 하나로 충분해진다(−0.025는 크기가 커서 재현 시 노이즈 논란이 작다). **rep2 확인 전까지는 관측으로만 제시. DEGEN·WELL 분해(voxel join)는 사전 등록 규칙이므로 정식 판정 전 필수 이행.** 발화율 평균 0.5는 "좁은 표적"이 아니라 "연속 가중"임을 병기한다.

## 결정 2 — 갈래: C(측정 기여) 주 서사 확정 + B(④′) 실행, A(타 prior) 기각

- **A 기각**: D1 기전(각이 좁을수록 prior 해로움)은 소스를 바꿔도 같으며 "왜 이번엔 다른가"의 근거가 없다(D6 규칙).
- **B 실행**: ④′ conf 연속판은 구현 완료 상태이고, 자유도 축소 계열의 유일한 미시험이자 표적성이 실측된 유일한 레버다. **이것이 마지막 lever 시험이며, 지면 D6의 ⓒ/ⓓ로 간다.**
- **C 주 서사 확정**: 주장 (B)가 실물이다 — 공식 지표 1위 기법이 crop 밖에서 19배 나쁘고 원거리 면이 0개. "지표가 안 재는 곳은 백지"는 평가 공백 서사의 가장 강한 실측이며 우리 crop 밖 채점 무대가 아니면 낼 수 없는 숫자다.
- **주장 (B) 공정성 조건**: C8 완화판 추출(cluster 필터 해제) 확인 전에는 "배경이 백지"를 확정하지 않는다. 기본 설정이 지운 것인지 학습이 안 만든 것인지 갈라야 한다. 서술은 실험 세션 문구("파이프라인이 배경을 버리도록 설계돼 있고 지표가 그것을 허용한다")를 유지한다.

## 결정 3 — DTU: 무대에서 빼지 않는다. 역할 = 적용 조건의 경계 증거

"위양성 검사 실패"는 08-10 스코프 판정(자기 가림 물체는 범위 밖)의 **정량 확인**이다. field가 위험으로 표시한 곳이 물체가 아니라 채점 밖 배경이었고 개입은 +0.016 손해였다 — "물체 무대는 본 방법의 적용 조건 밖"이 논증에서 실측이 됐다. 발표 배치를 "무해성 대조"에서 **"적용 조건" 슬라이드의 재료**로 변경한다. 무대에서 빼면 이 증거가 사라진다.

## 결정 4 — base2·use_mono 모두 승인, 우선순위 확정

rep2(진행 중) → **voxel join DEGEN·WELL 분해(CPU, 즉시)** → base2(가산형 노이즈 바닥, 2h) → ④′ conf 연속판 → C8 완화판 추출 → use_mono(DA3 세대 효과 분리, 40분 — 공정성 각주용, GPU 빌 때).

## 서사 현황 (발표·논문 골격)

1. 평가 공백 — **주장 (B)로 실측 완료** (공식 1위가 crop 밖 백지)
2. 학습 전 예측 — H1·H2 확정 자산
3. 개입의 어려움 — prior·예산중립 정규화 실패는 확정, 가산형은 "균일은 해롭고 차등은 무해" 관측(rep2 대기), ④′가 마지막 시험
4. 물체 무대는 적용 조건 밖 — DTU 실측으로 확인

## 실행 지시와 ④′ 순서 개정 (같은 날, 사용자 결정)

**④′ clone 억제를 이진 state 게이트로 먼저 실행한다.** 08-10에는 "연속판으로 바꾼 뒤 실행"을 조건으로 걸었으나, 순서를 뒤집는다. 근거는 둘이다. 이진이 가장 센 개입이므로 개념 자체에 신호가 있는지를 먼저 볼 수 있고(센 판에 신호가 없으면 부드러운 판은 볼 것도 없다), 과거 conf 게이트가 0발화한 이력이 있어 이진은 발화를 보장한다. 신호가 있으면 방향과 무관하게 conf 연속판으로 2차 런을 돌려 다듬고, 전혀 없으면 개념 종료로 보고 연속판을 생략한다. 연속판은 이미 구현되어 있어 추가 비용이 없다.

**실행 순서 확정**: ① global_rep2(GPU, 주장 A의 전제) ② DEGEN·WELL 축 분해(CPU, 동시 착수 — 이것 없이는 관측에 머무름) ③ base2(가산형 노이즈 바닥) ④ ④′ 이진판 ⑤ AmbiSuR·MILo 재추출(학습 불요, 주장 B 문구 확정의 전제) ⑥ use_mono(공정성 각주). GPU가 여럿이면 ①③④ 병렬 가능.
