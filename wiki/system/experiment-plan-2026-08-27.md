# 실험 계획 2026-08-27 — 증거 항 재설계 라운드

> 실험 세션 전용. 위에서 아래로 수행한다. **E1이 관문이고 E3은 E4 착수 전에 반드시 끝낸다.**
> **E1은 사람이 판정한다** — 코드는 그림까지만 만들고 멈춘다. 이유는 E1 항목 머리에 있다.
> 배경 설계는 `design-2026-08-26-naive-v0.md`, 현재 상태는 `research-status.md`.

## 0. 직전 라운드에서 나온 것 (이 계획의 출발점)

**된 것**
- MILo 코드에 같은 성격의 항이 **이미 있다.** 다만 `mesh.py:592`의 `* (labels > 0.5)` 마스크로 절반이 꺼져 있고, **근거가 자기 mesh 렌더라 순환한다**
- 우리 개입이 **잘못 채운 부피의 37%를 실제로 제거**했다

**안 된 것**
- 관 속(보어)은 못 뚫었다. 사후 삭제·학습 중 손실 두 형태 모두, 상수 6조합 전부 0.000
- 이유: SfM 점→카메라는 **직선**이라 U자관 속으로 들어가는 직선이 없다. 표적 부피에 증거가 **0.7%**만 닿는다
- **있어야 할 부피도 2.5배 더 지웠다**

**판정 (08-27)**
1. **증거와 문제는 배타적이 아니라 깊이에 따라 감쇠한다.** 개구부 근처는 여러 각도에서 직선이 들어가고, 깊이 들어갈수록 각도가 좁아져 0으로 수렴한다. U자관은 꺾이는 지점에서 0이 되는 **극단**일 뿐이다. 0.7%는 노선의 오류가 아니라 **전선의 위치**다
2. **주장을 줄인다**: "구멍을 뚫는다" → **"증거가 닿는 만큼 열고, 닿지 않는 곳은 표시한다"**
3. **과삭제는 원리 결함이 아니라 설계 결함이다.** 면 단위 삭제가 국소적·무규칙이라 생긴 것이며 전역 에너지로 푼다 (E4)
4. **X1 결과는 가설을 강화했다.** 차별 축이 "항이 없다"에서 **"항은 있는데 순환한다"**로 정확해졌다. MILo가 자기 렌더로 가시성을 판정한다는 것이 코드로 확인됐다

## 1. 무대

- **DTU scan65 · scan69만** 정성·정량 평가한다
- **trumpet은 본 무대에서 뺀다.** 꺾인 관은 직선이 들어가지 않아 이 기전의 사정권 밖이다. "여기까지가 한계"를 보이는 **경계 그림 한 장**으로만 쓴다

## 2. 실행 순서

### E1. SfM 점군이 hole을 담고 있는가 [관문 · 학습 불요 · 사람 판정]

**⚠ 이 항목은 코드가 구멍을 찾는 것이 아니다.** "구멍이 어디인가"를 자동으로 알 수 있다면 애초에 이 연구가 필요 없다 — 그것이 우리가 풀려는 문제 자체다. 순환을 피하려면 **정답이 파이프라인 밖에서 와야 한다.**

**E1의 정체는 증거원의 자격 심사다**: 사람이 정답(구멍 위치)을 아는 상태에서, **SfM 점군이 그 정답을 담고 있는가.**

- 담고 있으면 → 자동화 가능. 그때부터 코드가 판정한다 (E4)
- 안 담고 있으면 → 이 증거원으로는 영원히 못 한다 → 다른 증거원(E7)이나 상류 수정(E2)

**역할 분담을 지킨다**

| 단계 | 누가 | 무엇을 |
| --- | --- | --- |
| **E1a** | 코드 | 같은 카메라로 **입력 이미지 / SfM 점군 / 재구성 mesh** 세 장을 나란히 렌더. 여러 뷰 |
| **E1b** | **사용자 (육안)** | 셋을 비교해 (A)/(B)/(C) 판정 |
| **E1c** | 코드 | 사용자가 지정한 구멍 위치에서 점 분포를 정량화 |

#### E1b — 사용자가 판정할 것

| | 점군 상태 | 뜻 |
| --- | --- | --- |
| **(A)** | 구멍 자리에 점이 없다 (뚫려 있다) | 정보는 처음부터 있었고 **학습·추출이 메웠다** → E4로 진행 |
| **(B)** | 구멍 자리에 점이 찍혀 있다 (개구 평면 위) | **SfM 단계에서 이미 막혔다.** 광선이 그 점 앞에서 멈추므로 모순이 안 생기고 오히려 뚜껑을 지지한다 → **증거 역전.** 직전 라운드의 삭제 17면이 이것으로 설명된다 |
| **(C)** | 안팎 모두 아무것도 없다 | 관측이 닿지 않음 |

**(B)로 나와도 그 자체가 결과다** — "SfM 단계에서 이미 막힌다"는 아무도 짚지 않은 관찰이며, 문제가 학습이 아니라 파이프라인 최초 단계에 있다는 뜻이다.

#### E1c — 판정 뒤 정량

사용자가 구멍 위치를 지정하면(뷰 좌표 또는 3D 좌표), 그 근방에서:

- **개구 평면 기준 깊이 방향 분포** — 평면 바깥 / 평면 근처 / 안쪽 각각 몇 개
- 구멍 하나당 점 개수 (여러 구멍 평균)
- 같은 물체의 **일반 표면 구역과 비교** — 구멍 자리만 점 밀도가 다른지, 물체 전체가 그런지

### E2. 증거 회수 조건 완화 [E1과 함께]

- `min_track` 3 → 2. 지난 런은 3으로 **점의 52%(12,012/23,221)를 버렸다**
- `max_error` 완화. 어두운 영역의 점은 reprojection error가 클 수 있다
- **`--gt`를 반드시 지정한다.** 지난 런은 GT 없이 돌아 오카빙 검사(supported_ratio)가 통째로 빠졌다
- 서술 규율: 설정 조정은 "SfM을 개선한다"가 아니라 **"SfM이 보고하는 범위를 넓힌다"**로 적는다

### E3. `mesh.py:592` 마스크 확인 [E4 착수 전 필수]

`* (labels > 0.5)`로 기존 항의 절반이 꺼져 있다. 확인할 것:

- 의도된 설계인가 버그인가. 주석·커밋 이력·논문 서술과 대조
- **우리 항이 같은 자리에서 함께 꺼지는가** — 그렇다면 E4가 통째로 무력화된다
- "기존 가시성 항이 반만 작동한다"가 사실이면 그 자체를 기록한다 (판단 필요)

### E4. 면 삭제를 버리고 에너지 항으로 재구현 [본 실험]

지금의 "앞을 막는 면을 지운다"는 국소적·무규칙이라 낱개 면이 물체 전역에 흩어져 지워진다 — 2.5배 과삭제의 원인이다. 고전 Labatut은 삭제가 아니라 **전역 graph-cut**이며, 두 항의 균형이 과삭제를 원천 차단한다.

| 항 | 뜻 |
| --- | --- |
| 데이터 항 | 광선이 통과한 사면체는 **바깥**일수록 이득 (우리 증거) |
| 정칙화 항 | 라벨이 바뀌는 **경계 면적이 작을수록** 이득 |

- 낱개 면 하나 → 증거 이득은 작은데 새 경계 벌점이 크다 → **안 지워진다**
- 뚜껑 한 덩어리 → 증거 이득이 크고, 뚜껑 면이 사라지며 진짜 벽 면이 드러나 면적 변화가 작다 → **지워진다**

구현
1. 증거를 이진이 아니라 **연속량**으로. 사면체마다 "서로 다른 카메라 광선이 몇 개 통과했나" 누적
2. 그 값을 **MILo 기존 라벨링 에너지의 데이터 항에 더한다.** 새 메커니즘을 만드는 것이 아니라 **순환하지 않는 항을 하나 추가**하는 것이다
3. **정칙화 항은 MILo 것을 그대로 쓴다.** 그것이 과삭제를 막는 장치다
4. E3에서 확인한 마스크가 우리 항에도 걸리는지 반영

### E5. 정밀도·재현율 재측정 [E4의 판정]

| 지표 | 직전 값 | 기대 |
| --- | --- | --- |
| 잘못 채운 부피 **제거율** (재현율) | 37% | 유지 이상 |
| 있어야 할 부피 **오제거율** (정밀도) | **2.5배 초과** | **여기가 줄어야 성공** |
| 위상 지표 (성분 수·경계 변) | — | 숭숭 뚫리지 않아야 함 |
| Chamfer / F1 | — | 병기만. 주장 근거로 쓰지 않는다 |

**E4의 성공 조건은 재현율 상승이 아니라 정밀도 개선이다.**

### E6. 증거 깊이 프로파일

개구부에서 깊이별로 증거가 얼마나 닿는지 곡선을 낸다. 표적 부피 커버리지 0.7%가 **어느 깊이에서 0이 되는지**를 보이는 것이 목적이다.

- "증거가 닿는 만큼 연다"는 축소된 주장의 **수치 근거**가 된다
- scan65·69·trumpet 세 무대를 한 그래프에 겹치면 trumpet이 왜 사정권 밖인지가 한 장으로 설명된다

### E7. DA2·DA3 depthmap이 hole 깊이를 아는가 [E1과 독립, 병렬]

- scan65·69 학습 이미지 전량의 depthmap을 뽑는다
- 구멍 영역에서 깊이가 **주변 표면보다 깊게** 나오는지, 아니면 평평한지 본다
- **평평하게 나오면 그것도 결과다** — 모든 신호원이 이 구멍을 못 본다는 뜻
- **E1이 (B)로 나와도 이쪽은 살 수 있다.** SfM과 다른 증거원이다
- 서술 주의: **채우기(shape completion) 노선이 아니다.** 없는 곳을 지어내는 게 아니라 **비었다는 것을 확인**하는 용도다. 이 구분을 흐리면 계보 마디 5로 읽힌다
- MILo가 이미 depth order loss로 DA를 쓰므로 재료가 저장소에 있다

### E8. 좁은데 밝은 합성 보어 [여유 있을 때]

`research-status.md` §1-1 2×2 표의 **좌하단**이 비어 있다.

- 보어 블록에 **안쪽 벽 질감 + 조명**을 넣어 "좁지만 밝은" 케이스를 만든다
- 깊이/폭 비를 스윕해 **어느 비율부터 실패하는지** 곡선을 낸다
- 여기서도 실패하면 개구부(기하)만으로 실패한다 = **두 축이 진짜 독립**
- 잘 되면 어두움이 진짜 원인이다 = **축이 하나로 접히고 문제 정의를 다시 쓴다**
- **이것이 우리 방법의 최적 조건이다.** 여기서도 안 되면 방법 자체를 의심해야 한다

## 3. 공통 규율

- 데이터가 서버에 있으면 **서버에서 계산하고 로컬에는 결과물(그림·표·npz)만 내린다**
- `git add -A` 금지. 경로를 지정해 커밋한다
- 절대값을 타 논문 수치와 비교하지 않는다. 같은 metric 안의 상대 비교만
- 예비 결과에는 "단일 런·통계 전" 단서를 병기한다
- **방향 판단을 하지 않는다.** 판단이 필요하면 `EXPERIMENT.md`에 "판단 필요"로 남긴다
- 결과가 예상과 어긋나면 **그것을 먼저** 보고한다
