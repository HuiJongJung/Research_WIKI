# 깊은 구멍 표적 — 데이터셋·측도·선행 (Q-24)

> SURVEY_BRIEF Q-24. 표적 정의가 좁혀졌다: **관통 링이 아니라 깊은 오목·관·내부 공간.** 핵심 변수는 깊이 대 개구 비 — 깊을수록 내부가 스치는 각으로만 관측된다.
> **위상 필터 부적합 판정 반영**: 막힌 깊은 구멍은 genus 0이므로 Q-22의 Thingi10K genus 선별 기준은 이 표적에 쓸 수 없다.
> 조사일 2026-08-19. 깊이 대 개구 비의 수치는 별도 표기 없으면 조사 세션의 대략 추정이다.

## 1. 파이프·관 계열

### PipeForge3D — 부적합 판정 (Q-09 잔여 해소)

SBP-Net 원문 확인 `[원문 확인, arXiv 2606.04251 HTML]`. 정체는 데이터셋이 아니라 **자작 자동 생성기**다. "a custom automatic 3D pipe generator that produces models in both mesh and point cloud formats." 직각 커넥터로 임의 3D 그래프를 만들어 관을 배치하며, 50개 모델(각 ~100 부품) 생성. GitHub 공개(OfirGiladBGU/PipeForge3D). 라이선스는 저장소 미확인 `[미검증]`.

**그러나 대상이 관의 외부 표면이다.** 가는 구조 완성이 목적이며 내부 통로를 다루지 않는다. **새 표적(내부)에 부적합.** 외부 표면 관 무대가 필요해지면 재소환.

### 관 내부의 정답급 무대 — 내시경 계열 (인접, 관측 기하 상이)

**C3VD / C3VDv2** (Durr Lab, JHU) `[2차 자료 + 공식 페이지 확인]`.

- 실리콘 대장 팬텀을 **임상 HD 내시경 + 로봇 팔 궤적**으로 촬영. v2는 60개 팬텀 세그먼트에서 192 시퀀스, 169개 영상에 **GT 깊이·법선·광류·가림·6DoF 포즈·커버리지 맵·3D 모델** 제공
- GT 생성: 디지털 조각 모델을 3D 프린트·실리콘 코팅한 팬텀과, 로봇 궤적을 따라 가상 카메라로 렌더한 픽셀 단위 GT의 2D-3D 정합
- **관 내부 표면 + 정밀 GT + 실촬영**의 3박자를 유일하게 갖춘 무대
- **단 관측 기하가 다르다.** 카메라가 관 **안에** 들어간다. 우리 표적은 **외부 궤도에서 개구를 통해서만** 내부가 보이는 조건이다. 인접 무대이지 직접 답이 아니다 — "인접 항목, 직접 답 아님"

하수관·터널·보어 내부의 GS/NeRF 재구성 데이터셋은 **찾지 못했다** (탐색 경로 6절).

## 3. "깊이 대 개구 비"의 정량 측도

### 표준 측도 셋

| 측도 | 정의 | 표적 적합성 |
| --- | --- | --- |
| **Ambient Occlusion (AO)** | 표면점에서 반구 광선을 쏘아 막히지 않는 비율 | **가장 적합.** "그 점이 바깥에서 얼마나 보이는가"라서 **우리 관측 기하(외부 카메라의 도달 가능성)와 동형**이다. AO 낮음 = 깊은 내부 |
| **Shape Diameter Function** (Shapira·Shamir·Cohen-Or, The Visual Computer 2008) `[2차 자료 + 원문 PDF 존재 확인]` | 내향 법선 방향 광선으로 잰 국소 두께 | 두께 측도라 오목 "깊이"와는 다른 양. 보조(관·통로 판별) |
| Accessibility | 표면점에 접근 가능한 최대 구 반경 | AO의 기하판. 가공·분자 표면 계열 유래 |

세 측도 모두 mesh만 있으면 계산되므로 **렌더 축 후보의 사전 선별 지표**로 쓸 수 있다. "깊이 대 개구 비"를 직접 재는 단일 표준 측도는 찾지 못했고, AO가 그 대리로 가장 가깝다.

### 측도로 선별·채점한 재구성 선례

- **VolFill** (arXiv 2605.31466) `[2차 자료]`: 재구성 평가를 **visible / occluded / complete 부분집합으로 갈라** one-way Chamfer와 coverage를 따로 보고한다. **가시성 기준 부위 분해 채점의 직접 선례.** 단 과제가 amodal 생성(가려진 부분을 생성으로 채움)이라 인접
- **ObjSplat** (arXiv 2601.06997) `[2차 자료]`: self-occlusion과 back-face 가시성을 결합한 uncertainty로 능동 재구성을 유도. 용도가 능동(카메라 추가 가능)이라 인접
- AO/SDF로 **물체를 선별**해 재구성 벤치마크를 구성한 사례는 **찾지 못했다** — 우리가 하면 선별 기준 자체가 기여의 일부가 될 수 있는 빈자리

## 4. 깊은 오목·내부 재구성을 표적한 선행

- **VASE** (Wu 외, SGP 2011) `[2차 자료]`: 점군 복원 고전. "vase의 오목을 깊이 파내는" 것을 명시 표적 — 단 입력이 점군이며 다중 뷰 사진 재구성이 아니다
- **C3VD 계열** (1절): 내시경 — 카메라가 내부
- **TSPE-GS** (arXiv 2511.09944) `[2차 자료]`: 반투명 용기 너머의 표면 — 투명 축이라 별개
- **외부 궤도 + 개구 제한 관측으로 불투명 물체의 깊은 내부를 표적한 GS/NeRF 선행은 찾지 못했다.** SatSplat §4.5의 오목 자인(Q-23①)이 문제의 존재를 인정한 최근접이고, 표적으로 삼은 논문은 확인 범위에 없다. **빈자리 = motivation의 자리**

## 5. 정리 — M2에 넘기는 그림

- **촬영 보유**: OmniObject3D kennel·teapot(+ 목록 확인 후 mug·vase류), DTU scan65 안와·비강. 깊이 비를 크게 키우려면 촬영 보유 후보에는 없다
- **렌더 축**: Thingi10K·MedShapeNet에서 **AO 계산 선별**로 깊이 비 스펙트럼(1 → 5+)을 구성 가능. 깊이 비를 실험 변인으로 삼는 격자 설계와 정합
- **직접 제작**: 깊이 대 개구 비를 파라미터로 한 합성 물체(원통 보어 깊이 변화)가 가장 통제된 형태 — Q-22의 삽입 경로 3층 선례가 그대로 받친다
- 평가는 VolFill식 가시성 부분집합 분해 + Q-21 부위별 채점 규칙과 결합 가능
